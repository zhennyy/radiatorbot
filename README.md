# RadiatorPro Shop Bot

Telegram-бот интернет-магазина отопительного оборудования (радиаторы, полотенцесушители и т.д.): каталог с пагинацией, корзина, оформление заказа с доставкой, онлайн-оплата через ЮKassa и админ-панель для владельца магазина.

## Возможности

- 📦 Каталог товаров с постраничным просмотром
- 🛒 Корзина: добавление, уменьшение количества, удаление позиций
- ✅ Оформление заказа (ввод адреса доставки, проверка остатков на складе)
- 💳 Оплата через ЮKassa с автоматическим подтверждением по вебхуку
- 🔔 Уведомления владельцу о новых оплаченных заказах и о заканчивающихся товарах
- 🛠 Админ-панель (доступна только владельцу по `OWNER_CHAT_ID`): управление товарами, заказами и остатками

## Стек

- **Node.js** (20.x)
- [Telegraf](https://telegraf.js.org/) — фреймворк для Telegram-ботов
- [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) — хранение каталога, корзин и заказов
- [Express](https://expressjs.com/) — приём вебхуков от ЮKassa
- [Axios](https://axios-http.com/) — запросы к API ЮKassa

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/zhennyy/radiatorpro-shop-bot.git
   cd radiatorpro-shop-bot
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте файл `.env` в корне проекта со следующими переменными:

   ```env
   BOT_TOKEN=токен_вашего_телеграм_бота
   BOT_USERNAME=username_бота_без_@
   YOOKASSA_SHOP_ID=id_магазина_в_юкассе
   YOOKASSA_SECRET_KEY=секретный_ключ_юкассы
   OWNER_CHAT_ID=telegram_chat_id_владельца
   WEBHOOK_PORT=3001
   # DB_PATH=/path/to/shop.db  # опционально, для деплоя (например, на Railway)
   ```

4. Настройте в личном кабинете ЮKassa URL вебхука для события `payment.succeeded`, указывающий на `https://<ваш-домен>/yookassa-webhook`.

5. Запустите бота:

   ```bash
   npm start
   ```

## Команды бота

| Команда | Описание | Доступ |
| --- | --- | --- |
| `/start` | Приветствие и главное меню | все |
| `📦 Каталог` / `/catalog` | Просмотр каталога товаров с пагинацией | все |
| `🛒 Корзина` / `/cart` | Просмотр корзины и переход к оформлению заказа | все |
| Кнопка «✅ Оформить заказ» | Запуск сценария оформления заказа (адрес → подтверждение → оплата через ЮKassa) | все |
| `/orders` | Список оплаченных/обработанных заказов | владелец |
| `/addproduct Название \| Описание \| Цена \| Остаток \| Категория` | Добавление нового товара в каталог | владелец |
| `/stock <id_товара> <новый_остаток>` | Обновление остатка товара на складе | владелец |
| `/markshipped <id_заказа>` | Отметить заказ как отправленный (пользователю приходит уведомление) | владелец |

## Структура проекта

```
bot.js              — точка входа, регистрация команд и обработчиков
db.js                — подключение к SQLite и схема БД (с сидом тестовых товаров)
cart.js               — логика корзины
notify.js             — уведомления о низких остатках
webhook.js            — приём вебхуков ЮKassa, подтверждение оплаты
middleware/isOwner.js — ограничение доступа к админ-командам
payments/yookassa.js  — создание и проверка платежей через API ЮKassa
scenes/checkout.js    — сценарий оформления заказа
```
