# RadiatorPro — магазин в Telegram

Бот интернет-магазина отопительного оборудования (радиаторы, полотенцесушители): каталог, корзина, оформление заказа с доставкой по городам, оплата через ЮKassa, подбор товара с помощью Claude и веб-админка для владельца.

## Что понадобится

1. **Node.js 20 или новее** — проверь версию: `node -v`. Если не установлен, скачай с [nodejs.org](https://nodejs.org).
2. **Токен Telegram-бота**:
   - Открой Telegram, напиши [@BotFather](https://t.me/BotFather).
   - Команда `/newbot`, придумай имя и username.
   - BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его.
3. **Свой chat ID** (чтобы бот знал, кто владелец):
   - Напиши своему боту любое сообщение.
   - Открой в браузере `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates` и найди `"chat":{"id":...}` — это и есть `OWNER_CHAT_ID`.
4. **Магазин в ЮKassa** — для приёма оплаты:
   - Зарегистрируйся на [yookassa.ru](https://yookassa.ru), в личном кабинете возьми `shopId` и секретный ключ.
5. **API-ключ Anthropic** (для AI-подбора товаров):
   - Зайди на [console.anthropic.com](https://console.anthropic.com).
   - В разделе API Keys создай новый ключ и сохрани его (показывается только один раз).

## Установка

Открой терминал в папке проекта и выполни:

```bash
npm install
```

Создай файл `.env` в корне проекта:

```env
BOT_TOKEN=токен_от_botfather
BOT_USERNAME=username_бота_без_@
OWNER_CHAT_ID=твой_chat_id
YOOKASSA_SHOP_ID=id_магазина_в_юкассе
YOOKASSA_SECRET_KEY=секретный_ключ_юкассы
ANTHROPIC_API_KEY=твой_ключ_anthropic
ADMIN_USER=логин_для_веб-админки
ADMIN_PASS=пароль_для_веб-админки
WEBHOOK_PORT=3001
# DB_PATH=/data/shop.db  # опционально, для деплоя (например, на Railway с подключённым Volume)
```

В личном кабинете ЮKassa укажи URL вебхука для события `payment.succeeded`:
`https://<твой-домен>/yookassa-webhook`.

## Запуск

```bash
npm start
```

В консоли появится подтверждение, что бот и сервер вебхуков запущены — значит всё работает. Открой бота в Telegram и напиши `/start`.

Пока скрипт запущен в терминале — бот отвечает. Для постоянной работы 24/7 бот задеплоен на [Railway](https://railway.app) — там переменные окружения задаются в настройках проекта, а `shop.db` хранится на подключённом Volume, чтобы не пропадать при каждом деплое.

## Веб-админка

Доступна по адресу `https://<твой-домен>/admin` (логин и пароль — `ADMIN_USER` / `ADMIN_PASS` из `.env`). Пять вкладок:

- **Товары** — добавление/редактирование, загрузка фото с компьютера или по ссылке, остатки.
- **Заказы** — фильтр по статусу и поиск, карточка заказа по клику на строку (состав, доставка, промокод, оплата), смена статуса, выгрузка в CSV.
- **Промокоды** — создание кодов со скидкой, включение/отключение.
- **Доставка** — тарифы по городам с инлайн-редактированием цены, тариф по умолчанию для остальных городов.
- **Аналитика** — выручка и количество заказов за день/неделю/месяц, средний чек, топ товаров.

## Как это устроено

- `bot.js` — точка входа: регистрация команд, сцен, кнопок; AI-подбор через Claude API.
- `db.js` — SQLite (better-sqlite3): схема, миграции (`ALTER TABLE ... ADD COLUMN` с проверкой, чтобы не сломать продовую базу), сид тестовых товаров и тарифов доставки.
- `cart.js` — логика корзины.
- `notify.js` — уведомления владельцу о низких остатках.
- `webhook.js` — Express-сервер: приём вебхуков ЮKassa, REST API для админки (`/api/*`), раздача веб-админки (`/admin`) и загруженных фото (`/uploads`).
- `middleware/isOwner.js` — ограничение доступа к владельческим командам.
- `payments/yookassa.js` — создание и проверка платежей через API ЮKassa.
- `scenes/checkout.js` — сценарий оформления заказа (город доставки кнопками → адрес → промокод → оплата).
- `admin-public/index.html` — веб-админка, один файл (HTML/CSS/JS без сборки).
